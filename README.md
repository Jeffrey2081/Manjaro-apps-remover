# Manjaro Apps Remover

A simple script to remove unwanted pre-installed applications from Manjaro Linux.

## Features
- 🗑️ Remove bloatware applications that come pre-installed with Manjaro.
- ⚡ Lightweight and easy to use.
- 💻 Supports multiple desktop environments.

## Prerequisites
Ensure you have `git` installed:
This command updates the entire system and installs git
```bash
sudo pacman -Syu git
```

## Installation
Clone the repository:
```bash
git clone https://github.com/Jeffrey2081/Manjaro-apps-remover.git
cd Manjaro-apps-remover
```

Make the script executable:
```bash
chmod +x remove-apps.sh
```

## Usage
Run the script with:
```bash
./remove-apps.sh
```
Follow the on-screen prompts to select and remove applications.

## Compatibility
✅ Tested on:
- Manjaro XFCE
- Manjaro KDE
- Manjaro GNOME
